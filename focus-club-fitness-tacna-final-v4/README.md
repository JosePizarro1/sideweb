# Focus Club Fitness Tacna — Landing Page

Landing page profesional para la única sede de Focus Club Fitness en Gregorio Albarracín, Tacna.

## Contenido del proyecto

- Landing responsive para escritorio, tablet y celular.
- Secciones de experiencia, entrenamientos, productos y ubicación.
- Accesos directos a WhatsApp, Facebook, teléfono y Google Maps.
- Imágenes optimizadas para web.
- Metadatos para buscadores y vista previa al compartir el enlace.
- Guía completa de identidad visual y criterios UI/UX.

Consulta [`GUIA_IDENTIDAD_UI_UX.md`](./GUIA_IDENTIDAD_UI_UX.md) antes de realizar cambios visuales.

## Requisitos

- Node.js 22.13 o superior.
- npm.

## Instalación

```bash
npm install
npm run dev
```

Para generar la versión de producción:

```bash
npm run build
```

## Archivos principales

- `app/page.tsx`: contenido y estructura de la landing.
- `app/globals.css`: identidad visual, animaciones y responsive.
- `app/layout.tsx`: título, descripción y metadatos sociales.
- `public/`: logotipo, fotografías e imágenes de productos.
- `GUIA_IDENTIDAD_UI_UX.md`: sistema visual y reglas de diseño.
